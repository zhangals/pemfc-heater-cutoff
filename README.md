# PEM fuel-cell cold start

Code and simulation results for **Heat redistribution and temperature reserve after heater cutoff in a PEM fuel-cell cold start**.

```sh
python -m pip install -r requirements.txt
python run_example.py
```

The five-cell example returns a heater input of 5014.12 J and a minimum cell temperature of 1.094 °C over 120–180 s. [Data and reproduction instructions](REPRODUCE.md).
