# Calibration and heater-search records

Run the commands from the repository root, using the packages pinned in requirements.txt.

- [Joint-fit trials](joint_fit_trials.csv) contain all 40 archived parameter evaluations, including the checkpoint used to retain trial 19. [Single-temperature trials](single_fit_trials.csv) contain the coefficients, objective and aggregate errors for all 192 evaluations, in evaluation order within each start. [Fit protocol](fit_protocol.json) gives the parameter order, bounds, initial values, historical load convention, residual weights and stopping rules. To verify these objectives and selections, run `python research/revision_v13/calib/check_fits.py`.
- [Heater designs](../../../results/stack/search_evaluations.csv) and [winners](../../../results/stack/search_chains.csv) contain all 384 evaluations in the 12 search chains. The [acquisition history](bayes_acquisitions.csv) includes both fitted kernels, training indices, probabilities, and the acquisition value at the selected control for each of the 288 adaptive steps. To regenerate every initial command and refit both feasibility models at every adaptive step, run `python research/revision_v13/calib/replay_search.py`. This command uses the previously calculated outcomes of earlier designs. To integrate an entire search chain again, follow the main REPRODUCE.md.
- Single-cell fits require the original Problem B Attachment 2 workbook from the 2026 China Post-Graduate Mathematical Contest in Modeling. With a locally held copy, run `python research/revision_v13/calib/replay_single_start.py --workbook local_inputs/attachment_2.xlsx --trials research/revision_v13/calib/single_fit_trials.csv --temperature -25 --start 1 --output refit.json`. Select either starting vector and either training temperature. Output contains trial parameters, losses and completion status. New single-temperature fits use column E, the tabulated current density.
